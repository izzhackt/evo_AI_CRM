# University PDF font

Noto Sans Regular, unchanged from EVO Docs `6e7cf741`, is embedded in synthetic
university PDF output. It covers tested Latin/Cyrillic text, not universal Unicode.
Missing code points or empty outlines stop filling; no host-font fallback is used.

- Source: https://raw.githubusercontent.com/notofonts/noto-fonts/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf
- License: [SIL Open Font License 1.1](OFL.txt); retain this notice with the font.
- Source retrieval: 2026-09-10; ported 2026-09-13.
- SHA256: `b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5`.

Real template/font/layout approval and runtime asset tracing remain mandatory
before a public export route is introduced.
