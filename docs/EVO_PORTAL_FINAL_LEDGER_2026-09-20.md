## Известные ограничения всего продукта

- Единственный live-прогон с реальным аккаунтом — owner-QA на wave-5 iOS-сборке (favorites round-trip, языковой цикл 196, просмотр сидовых уроков/профессий; receipt r35446304360) плюс точечные live-чеки ревьюеров (#877 approve full-chain, #890 route-фикс) и авторизованный read-only smoke входных путей (инцидент 186). Все write-флоу вне этого прогона (регистрация/инвайт, документы iOS, чат, консультация, раннеры уроков/тестов) против прод не exercised.
- iPhone: весь код в main, тесты 139/139, но дистрибуции нет — ни TestFlight, ни App Store; телефонный флоу wave-9a включён релизом b047e663, но end-to-end не пройден.
- KY-тексты всего портала ждут вычитки носителем (стоящий пункт receipts начиная с d1b64849).
- iOS-Главная — базовая (статус дела + следующий шаг), без паритета с веб-Главной PORT-9c.
- Ручной VoiceOver-проход iOS не выполнялся (только статические label/traits); live filtered-RPC iOS не гонялся.
- 4 pre-existing локальных падения `test:ci:node` на main (CI зелёный; вынесено отдельной задачей, receipt 5ab34127).
- Полная построчная ре-верификация лицензий фото не выполнена (только спот-чеки).
- Host-side systemd-юниты KB из #906 не установлены — knowledge-maintenance job не выполняется (портал не деградирует; scope Astra).

## Владельческие внешние шаги (не считаются «готово»)

1. Apple Developer / DUNS, подпись, App Store Connect: доступ, membership, TestFlight-дистрибуция, store-метаданные + privacy disclosures по фактическому сбору, решение Apple review (план §13; без этого писать «опубликовано» нельзя — план строка 416).
2. Вычитка KY носителем языка (стоящий PORT-6 пункт receipts начиная с d1b64849).
3. Resend SMTP и переадресация ответов: одобрено, активация ожидается (PLAN_CHANGES:30583).
4. Dependabot: 3 открытых уведомления названы при передаче; в репо-доках не зафиксированы (последний зафиксированный readback — ноль, EVO_LAUNCH_PLAN:1235) — проверить на GitHub и решить по обновлениям.
5. Установка и включение host-side systemd-юнитов `deploy/knowledge/*.service|*.timer` из #906 на hermes-vps (Astra/владелец; receipt fd25b1ac — «кто ставит, порталом не решено»).
6. Live-прогон новых флоу с QA-аккаунтом: регистрация и инвайт (web+iOS), загрузка/скачивание документов на iOS, чат, консультация, write-пути раннеров, render managed-фото под авторизацией.
