## Правила имён

- Файлы — строчными буквами через дефис: `2026-10-27-wazzup-whatsapp-plan.md`.
- Если у документа есть дата, она стоит в начале: `YYYY-MM-DD-тема.md`.
- Закрытый план переносится в `archive/plans/` командой `git mv`; в журнале
  `PLAN_CHANGES.md` записывается старый и новый путь.
- Прошлые записи `PLAN_CHANGES.md` не переписываются.

## Как поддерживать документ

В начале важного документа указывайте владельца, статус
(`Draft` / `Active` / `Verified snapshot` / `Archived`), дату проверки и
источники. Не публикуйте догадки как подтверждённый факт. Если отчёт и
[`platform/current-status.md`](platform/current-status.md) расходятся, сначала
проверьте дату и источник, затем обновите документ-владелец.

Это публичный репозиторий: персональные данные, телефоны, ключи, корпоративные
оригиналы и банковские реквизиты сюда не попадают (см.
[границу бренда и компании](company/README.md)).
