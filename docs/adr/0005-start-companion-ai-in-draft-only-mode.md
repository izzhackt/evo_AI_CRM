# Start companion AI in draft-only mode

> Status: superseded by ADR 0020; companion-era historical source only.

The Companion WAHA CRM App will launch its AI assistant in draft-only mode: staff may generate suggested replies, but automatic WhatsApp replies remain disabled by default. This lets EVO evaluate WACRM's own AI behavior on real conversations without allowing a newly converted WAHA transport to send unattended customer messages.
