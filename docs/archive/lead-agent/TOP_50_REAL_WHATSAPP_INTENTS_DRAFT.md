copying customer messages into Git. The archive contains 541 chat files. The
strict filter admitted 535 direct chats and 2,102 inbound non-empty text
messages. The version-1 catalog matched 304 messages; one message may match
multiple intents.

The ranking uses unique-chat count first and message count second so one long
conversation cannot dominate the result. It is a discovery draft, not yet a
golden dataset: low-frequency ranks and the unmatched remainder require manual
review before the owner approves the final Top 50.
