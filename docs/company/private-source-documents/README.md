# Private Source Documents

PDF files in this folder are local restricted originals and are ignored by Git.
The expected filenames and checksums are listed in
[`../source-documents.md`](../source-documents.md).

Keep directory permissions limited to the local owner. Do not attach these files
to GitHub issues or pull requests. The charter contains personal identity data,
private addresses, ownership information, and signatures; the bank document
contains payment requisites.
