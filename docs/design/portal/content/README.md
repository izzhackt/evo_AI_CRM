# Учебный контент портала (PORT-4)

Источники правды этого каталога:

- `english-module-1-draft.json` — «Английский. Модуль 1 — старт»: 12 уроков,
  99 заданий (70 choice, 10 matching, 13 short_answer, 6 чтения). Метод и
  ограничения — `english-module-1-notes.md`.
- `professions-draft.json` — 24 карточки профессий с покрытием всех 8 шкал
  ORVIS. Политика источников (O*NET, CC BY 4.0) — `professions-notes.md`.

Резолюции открытых вопросов движка (нормализация short_answer, порог
«урок пройден», экран итога) зафиксированы в `docs/PLAN_CHANGES.md`
(запись «PORT-4a: движок обучения и профессий (миграция 198)»).

## Generation and checks

Конвейер зеркалит assessment-контент (`supabase/assessment-content/README.md`).
Используйте Node 22 репозитория:

```bash
node scripts/generate-portal-learning-seed.mjs --check
node --test scripts/test-portal-learning-content.mjs
```

Генератор по умолчанию печатает детерминированный SQL; `--write` механически
перегенерирует НЕприменённую миграцию 199. `--check` сверяет SQL и sha256
источников байт-в-байт. После применения 199 **эти опубликованные v1-файлы не
редактируются и миграция не перегенерируется**: новая версия контента — новый
номер forward-миграции. `ON CONFLICT DO NOTHING`, скрывающего расхождения,
здесь нет, обновления существующих версий — тоже.

Оффлайн-проверки работают по фактическому содержимому файлов; они не
доказывают методическую выверенность KY-текстов (нужна вычитка носителем,
зафиксировано в notes как шаг перед публикацией) и не заменяют boundary-тест
движка на чекпоинте 198.
