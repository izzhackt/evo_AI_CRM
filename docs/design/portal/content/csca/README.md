# Подготовка к CSCA: контент

Источник правды контента CSCA для миграций контента. Выпуск 1.0.0 (часть 1, пилот)
применён миграцией `286_platform_csca_math_part1.sql` и заморожен: генератор только
сверяет её sha256. Выпуск 1.1.0 (часть 2) генерируется в миграцию
`305_platform_csca_math_part2.sql` (302..304 заняты PR #1248, он сливается первым); файлы
ищутся по имени, содержимое от номера не зависит. Веб и iPhone получают контент только через RPC движка 285, контракт:
`docs/portal/csca-contract.md`.

|---|---|
| `sessions.json` | календарь сессий CSCA с csca.cn, дата проверки, окно регистрации только там, где оно опубликовано (в 286, во вторую миграцию не повторяется) |

| `math/lessons/*.json` | 28 уроков из типизированных блоков; генератор добавляет к каждому практику (56 уроков движка). Пилотные `l01..l03`, остальные `tNN-<тема>` (NN порядок темы) |

Выпуск = полная копия содержимого (контракт §16): 1.1.0 несёт всё из 1.0.0 без
изменений (тела заданий, теория, рисунки, порядок упражнений; это проверяет
node-тест по тексту 286 и SQL-набор `platform_csca_math_part2.sql`), плюс 25 новых
тем. Ключи стабильны, поэтому прогресс, журнал ответов и банк ошибок учеников
остаются в силе. Формы пилота (`-1`, 3 и 6 заданий) заменены полными с новыми ключами
(`-2`); все их задания вошли в новые формы.

Правила (план v2 §9.5, дизайн модуля §6): только свои задания, официальные
образцы и программы не копируются и не пересказываются (`provenance.
official_sample_consulted: false`); итог называется «оценка EVO», не «балл
CSCA»; без логотипов CSC и CSCA и слов «официальный партнёр»; решается без
калькулятора; без длинных тире. Кыргызский текст написан без носителя языка:
`ky_review: pending` до вычитки. Предметное ревью (`subject_review`) ждёт
назначения владельцем; до него действуют две автоматические проверки и кнопка
«Сообщить об ошибке».

## Генерация и проверки

```bash
node scripts/portal/generate-csca-content-seed.mjs --check   # 286 заморожена по sha256, часть 2 совпадает с источниками
node --test scripts/portal/test-csca-content-seed.mjs
bash scripts/test-csca-learning-postgres.sh   # одноразовая БД: 285 и 286, обновление до 1.1.0 с прогрессом ученика
```

`--write` перегенерирует НЕприменённую миграцию части 2 (если файла нет, создаёт
его со следующим свободным номером). После её применения опубликованные файлы не
редактируются: новая версия в `release.json` и новая forward-миграция со следующим
свободным номером. Уроки части 2 (кроме трёх пилотных) написаны и проверены тремя
способами: автопроверки генератора, независимое решение всех заданий отдельным
решателем и правки по замечаниям; детали в `math/verification-part2.md`.

## Что ещё нужно человеку

Предметное ревью (`subject_review: pending`) и вычитка кыргызского текста носителем
(`ky_review: pending`) ждут владельца; пока работают две автоматические проверки и
кнопка «Сообщить об ошибке». Второй решатель-человек не привлекался. У 7 тем
плановых уроков больше одного (`lessons_planned` > 1), написан один.
Практика по теме пока 2 или 3 задания при цели не меньше 6, пробных форм одна вместо двух
непересекающихся (DESIGN §3, §8.2).
