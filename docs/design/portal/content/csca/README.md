# Подготовка к CSCA: контент

Источник правды контента CSCA для миграции контента (сейчас
`supabase/migrations/286_platform_csca_math_part1.sql`). Веб и iPhone получают
его только через RPC движка 285, контракт: `docs/portal/csca-contract.md`.

| Файл | Что внутри |
|---|---|
| `sessions.json` | календарь сессий CSCA с csca.cn, дата проверки, окно регистрации только там, где оно опубликовано |
| `math/release.json` | выпуск трека `csca-math`: ключ модуля, версия, название, ссылка на страницу программы |
| `math/topics.json`, `math/syllabus.md` | 4 модуля программы, 12 пунктов, 28 тем своими словами EVO, оценка весов для пробного |
| `math/items.json` | 30 своих заданий: условие EN, 4 варианта, разбор каждого RU и KY, решение, термины |
| `math/lessons/*.json` | 3 урока из типизированных блоков; генератор добавляет к каждому практику |
| `math/forms.json` | диагностика (3 задания, 4 минуты) и пробный тест (6 заданий, 75 с на задание, без досрочного завершения) |
| `math/figures/*.svg`, `index.json` | 9 рисунков по профилю SVG, alt RU, KY, EN, sha256 |
| `math/verification.md` | независимое решение всех 30 заданий (совпало 30 из 30) и замечания E1..E9 |

Это часть 1 (пилот). Правки проверки применены 16.10.2026: формулировки
заданий 25, 19 и 18 (E4, E5, E6), E1 (запись степени в задании 8), E2 (разбор
варианта a задания 6), E3 (решение задания 2 без буквы варианта), E7 (условие
задания 17), E8 (термины «rate of change» и «critical point» введены в тексте
урока 2). E9 без правки: рисунки верны.

Правила (план v2 §9.5, дизайн модуля §6): только свои задания, официальные
образцы и программы не копируются и не пересказываются (`provenance.
official_sample_consulted: false`); итог называется «оценка EVO», не «балл
CSCA»; без логотипов CSC и CSCA и слов «официальный партнёр»; решается без
калькулятора; без длинных тире. Кыргызский текст написан без носителя языка:
`ky_review: pending` до вычитки. Предметное ревью (`subject_review`) ждёт
назначения владельцем; до него действуют две автоматические проверки и кнопка
«Сообщить об ошибке».

## Генерация и проверки

```bash
node scripts/portal/generate-csca-content-seed.mjs --check
node --test scripts/portal/test-csca-content-seed.mjs
bash scripts/test-csca-learning-postgres.sh
```

`--write` перегенерирует НЕприменённую миграцию контента. После её применения
опубликованные файлы не редактируются: новая версия в `release.json` и новая
forward-миграция со следующим свободным номером.
