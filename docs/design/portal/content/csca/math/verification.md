## Неоднозначные условия и два защитимых ответа

Жёстких случаев нет: ни у одного задания нет второго варианта, который можно защитить как верный. Слабые места формулировок (ответ не меняют, но можно улучшить):

- **E4. Задание 25** ("Find b."). Вариант B `b = 2` сам по себе верное значение b, но неполное (нужны оба: ±2). Ключ A корректен, но ученик с хорошим английским может возразить. Предложение: "Find all possible values of b."
- **E5. Задание 19.** Условие просит "find the one with the smallest slope", а варианты это уравнения. Предложение: "find the equation of the tangent line with the smallest slope."
- **E6. Задание 18.** "Increasing" допускает f' = 0 в изолированной точке (a = 0, f = x³). Ключ B верен и при строгом, и при нестрогом определении (x³ строго возрастает), поэтому ответ не зависит от определения. Дистрактор A ("a > 0") это типичная ошибка, он разобран правильно. По желанию можно написать "strictly increasing", чтобы убрать любой спор.

## Ошибки в объяснениях

Математических ошибок нет. Все числа в `solution_ru` и `explain_ru` верны, включая происхождение каждого дистрактора (например 8/15 в задании 10, 7/5 в задании 30, 3√2/2 в задании 28, `y = -3x + 5` в задании 19 проверены обратным пересчётом). Редакторские замечания:

- **E1. Задание 8, `solution_ru[1]` и `solution_ky[1]`.** Запись `-2 = \log_{1/2} \left(\frac{1}{2}\right)^{-2} = \log_{1/2} 4` читается неоднозначно: степень можно отнести к самому логарифму, и тогда выйдет (log_{1/2}(1/2))^{-2} = 1. Значение верное, запись нет. Предложение: `-2 = \log_{1/2}\left(\left(\frac{1}{2}\right)^{-2}\right) = \log_{1/2} 4`.
- **E2. Задание 6, вариант A.** Объяснение "взяли b = 0, потому что график проходит через начало координат" не даёт объяснить ответ 2: при b = 0 из точек рисунка выходит a = 1 или a = √3, но не 2. Вероятная реальная ошибка ученика: нашёл a = 2 и забыл прибавить b. Утверждения в тексте истинные, но диагноз дистрактора ненадёжный. Предложение: "нашли a = 2 и не прибавили b".
- **E3. Задание 2, `solution_ru[1]`.** "Перепишем вариант c)" ссылается на латинскую букву c (в KY тоже "c) вариантын"). В данных id вариантов `a`..`d`; если интерфейс покажет А-Б-В-Г или A-D, ссылка рассинхронизируется. Предложение: ссылаться на само выражение: "Перепишем $\left(\frac{1}{2}\right)^{-x}$".
- **E7. Задание 17, английский.** "Its position at time $t$ seconds is $s(t) = t^2 + 3t$ meters" звучит неловко. Предложение: "At time $t$ (in seconds), its position is $s(t) = t^2 + 3t$ meters."
- **E8. Урок 2, блок terms.** В глоссарии есть `critical point` и `rate of change`, но в тексте урока они нигде не введены (нужны только в блоке terms). Либо назвать точки f' = 0 "критическими" в блоке 7, либо убрать термины.
- **E9. Задания 6, 15, 26 зависят от рисунка.** Это задумано. `alt_en` / `alt_ru` содержит всю нужную информацию (асимптота, три точки, нули производной, знак, центр), поэтому доступность обеспечена. Замечаний к самим рисункам нет: масштаб осей, подписи и формы кривых соответствуют условиям.

## Уроки (3 шт.)

Математических ошибок нет.

- **L1 (exp/log):** определение логарифма, ограничения a > 0, a ≠ 1, b > 0, таблица свойств двух функций, зеркальная симметрия относительно y = x, правила произведения, частного, степени, формула перехода. Разбор 1: x² - 1 = 3, x = ±2, остаётся x = 2 (проверка: log3 3 + log3 1 = 1). Разбор 2: 2^0.3 > 1, 0.3² = 0.09, log2 0.3 < 0, порядок верный. Подсказка про 2^10 = 1024, 3^5 = 243, 5^3 = 125 и 2 < log2 5 < 3 верна.
- **L2 (производная):** наклоны секущих 4 и 3 и касательной 2, касательная y = 2x - 1 в P(1, 1); таблица производных и правила суммы, произведения, частного верны. Разбор 1: y = x - 4. Разбор 2: f'(-3) = 15, f'(0) = -12, f'(3) = 15, максимум 16 при x = -2, минимум -16 при x = 2. Замечание только E8.
- **L3 (прямая и окружность):** формулы наклона, перпендикулярности (k1·k2 = -1), расстояния от точки до прямой, |AB| = 2√(r² - d²). Разбор 1: центр (-1, 2), r = 3. Разбор 2: d = |−4 − 6 + 5|/5 = 1, половина хорды 2√2, |AB| = 4√2; рисунок `circle-chord` с этим согласован численно.
- Ссылки `check_items` и `practice_items` во всех трёх уроках указывают на существующие задания нужных тем и pool (lesson / practice). Prerequisite-ключи есть в `topics.json`.
