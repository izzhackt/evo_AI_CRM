# Портальный дизайн-контракт EVO admissions (PORT-2)

Статус: выбранное направление Fable по полномочию плана §7. Связан с корневым
`DESIGN.md`: бренд (красный #d70217, Golos Text, JetBrains Mono для данных,
оригинальный логотип, светлая+тёмная темы) — общий; всё остальное ниже —
контракт портала, изолированный от staff CRM. Правило staff-CRM «тихий
интерфейс» на портал не переносится автоматически (план §7), но предметность
текста — переносится (план §7, тексты).

## Направление: «Атлас»

Портал — атлас будущего студента: карта, кампусы, профессии как места
назначения. Фотография и карта несут цвет и атмосферу; интерфейс вокруг —
спокойный, тёплый, крупная типографика. Не «CRM для школьника» и не клон
Duolingo: исследование и понятный следующий шаг.

Принципы: (1) один заметный главный шаг на экране; (2) фото/карта — контент,
не декорация: только реальные кампусы с атрибуцией; (3) выразительность за
счёт масштаба, глубины и движения, а не количества цветов; (4) все состояния
честные: пусто/ошибка/загрузка/нет координат/нет перевода.

## Токены (`--pt-*`, файл src/app/(portal)/portal.css)

  `#191714`, вторичный `#6b6660`, линия `#e7e3dd`, акцент `#d70217` (действия,
  прогресс, активная навигация), success `#177245`, warn `#b45309`,

- Тёмная: фон `#141311`, поверхность `#1e1c19`, текст `#f2efe9`, вторичный

  светлота для контраста), семантика соответственно. Обе темы обязательны.
- Типографика: Golos Text; шкала 32/24/20/17/15/13, плюс 12 только для подписи
  вкладки нижней панели телефона (#1113); данные (даты, дедлайны,
  суммы) — JetBrains Mono 13/15. Межстрочный 1.4–1.5. KY и RU — одна шкала.
- Радиусы: карточка 16, элемент 12, контрол 10, чип 999.

## Тема — решение владельца 02.10.2026

Источник: [PLAN_CHANGES](../../PLAN_CHANGES.md), запись 02.10 «тема кабинета
студента». Заменяет прежнее «тёмная — по `prefers-color-scheme`».

- **По умолчанию светлая** для всех; тёмная — только выбор студента. Тема
  ОС/телефона не читается нигде на вебе (iPhone-приложение по-прежнему
  следует теме телефона — отдельный продукт).
- **Одна кнопка «солнце/луна»** (`src/components/ThemeToggle.tsx`), без
  пункта в настройках: верхняя полоса кабинета рядом с аккаунтом (видна и
  на телефоне), шапки `/apply`, `/apply/status`, `/login`,
  `/platform-pending`. Цель 44×44, видимый фокус, постоянное имя
  «Тёмная тема» / KY «Караңгы тема» + `aria-pressed`; значок — текущая тема.
- **Механизм:** cookie `theme` (`dark|light`, путь `/`, 1 год, SameSite=Lax),
  корневой layout ставит `<html data-theme>` и `color-scheme` на сервере —
  без вспышки и без скрипта. Хост сотрудников всегда светлый и без кнопки;
  cookie привязана к хосту, выбор на app.* до crm.* не доходит.
- **Токены:** светлые — база `.pt-shell`, тёмные — `:root[data-theme="dark"]
  .pt-shell`. Компоненты используют только `--pt-*`, без своих цветов.
- **Смена:** только цвета (раскладка не сдвигается), переход ≤ 200 мс на
  время нажатия (`data-theme-switching`), не при загрузке; при
  `prefers-reduced-motion` — мгновенно. Карта MapLibre меняет стиль на
  лету (`setStyle`, без пересоздания): светлая — OpenFreeMap `positron`,
  тёмная — `dark`.

|---|---|---|---|

**Правила подсветок:** одна подсветка — `--pt-wash` на фоне страницы
(`.pt-content`), сверху-слева, гаснет к ~420 px и прокручивается со
страницей; поверхности, текст и фото её не получают. Красный в подсветке —
не больше 5–7 % и только как тон, не как пятно. Градиентный текст,
стекло и свечение запрещены. Тени светлой темы — тёплого тона бумаги
(`rgb(54 38 22 / …)`), всегда с отступом и размытием; в тёмной глубину
даёт линия. Красный `#d70217` (тёмная `#ff4a57`) — бренд, главное действие,
активная навигация; новых красных мест тема не добавляет.

## Карта экранов и навигация

Web (десктоп приоритетен): левый рейл (иконка+подпись), верхняя полоса с
логотипом, поиском и колокольчиком уведомлений.

Web на телефоне (≤ 767 px): нижняя панель — первые три раздела уровня доступа и
«Ещё»; остальные разделы открывает лист над панелью. Ни один раздел не уходит
за край экрана, цель каждой вкладки ≥ 44 px, подпись вкладки 12 px (#1113).
Оригинальный логотип в тёмной теме стоит на белой подложке: чёрный словесный
знак не читается на тёмном фоне, а инверсия logobook (стр. 11–12) задана только
на фирменном красном; белый вариант для нейтрального тёмного — решение
владельца бренда (#1116).

iPhone: таб-бар, состав зависит от `accessTier`:
- approved: Главная · Университеты · Профессии · Английский · Профиль
- assisted: Главная · Моё поступление · Университеты · Английский · Профиль
  (Профессии остаются с Главной и из поиска)

Разделы (веб и iPhone — одни возможности, разная компоновка):
1. **Главная** — «продолжить» (урок/тест/анкета-статус), избранное с ближайшими
   интейками, новое в каталоге; assisted: ближайшие действия дела (существующая
   next-step модель) первым блоком.
2. **Университеты** — список⇄карта (MapLibre), фильтры страна/уровень/поиск;
   карточка вуза: фото (атрибуция), факты, программы с интейками, избранное.
   Вуз без координат живёт только в списке — без фиктивных точек.
3. **Профессии** — карточки по интересам; карточка: день/среда/навыки/
   интересное-сложное/пробное задание/куда учиться (ссылки на программы);
   вход в тест orvis92; зарплаты/работодатели — только с источником.
4. **Английский** — модуль уроков (прогресс, повторение ошибок), вход в
   english36, история попыток.
5. **Избранное** — вузы/программы, сравнение фактических свойств.
6. **Профиль** — данные, язык RU/KY, личные результаты тестов, настройки,
   выход, инициирование удаления аккаунта (App Store §5.1.1(v)).
7. **Моё поступление** (assisted) — обзор/документы/оплата/вопрос куратору в
   новом визуале; функциональные контракты не меняются.
8. **Входные**: анкета (шаги, возврат, сохранение), ожидание решения,
   отклонено/отозвано — честный статус и допустимое действие.

## Правила состояний и текста

- Состояние видно всегда: сохранено/отправлено/загружается/ошибка+как
  исправить. Повторная отправка безопасна (идемпотентность уже в RPC).
- Пустое состояние: что отсутствует + одно действие. Без AI-slop, без
  технических терминов (RLS/RPC/Supabase), без «Здесь вы можете…».
- Недоступное по уровню доступа не показывается как замок-дразнилка:
  approved не видит разделов сопровождения вовсе (кроме честного статуса
  анкеты/доступа).
- Дедлайны: абсолютная дата + мягкое «окно закрывается через N дней» при
  N≤60; никаких процентов готовности.

## iPhone-специфика

SwiftUI, iOS 17+, системная типографика заменяется на Golos (bundle,
лицензия уже в бренде) с Dynamic Type; safe areas; системный файловый пикер
для документов (assisted, PORT-5); pull-to-refresh; offline: честная плашка
«нет сети» + повтор, без притворного кэша. Иконка приложения — адаптация
оригинального знака EVO (без перерисовки логотипа).
