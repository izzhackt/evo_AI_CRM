# iPhone: карточка университета — refinement, 2026-09-20

Статус: реализация и точечная проверка завершены, независимый review в PR.
Контракт принят к исполнению по прямому поручению владельца
«critique → plan → do». Base `485f3ce0`.

## Результат и границы

Абитуриент быстро находит программы выбранного вуза, читает факты и наборы,
открывает официальные сведения или консультацию. Сохраняются идентичность
EVO/«Атлас», реальные фото, авторство/лицензия, полные данные, URL, локали RU/KY,
навигация, избранное, форма консультации и все состояния загрузки/ошибки.

Разбор: [Impeccable snapshot](ios-university-refinement-critique.md).
Два независимых assessment; 24/36 — экспертная оценка, не бизнес-приёмка.

## Изменения

- Название/место и переход к программам с фактическим количеством — в начале.
- Фото и компактное native-раскрытие полной атрибуции.
- Существующий CTA с явной зоной нажатия не менее 44pt.
- Программы до официальных ссылок; один фон программы, разделители наборов.
- Читаемые подписи, адаптивные строки фактов, headings для accessibility.
- Официальные сведения и дата проверки остаются доступными после программ.

Только SwiftUI-представление и необходимые RU/KY строки. Не меняются services,
Auth/RLS, схема, данные, вычисление дедлайнов/статусов, форма отправки и общий
TabView. Сборка/установка в текущий Simulator без удаления данных приложения.

## Приёмка

Сборка iOS Simulator; настоящий каталог → AGH → программы → атрибуция/ссылки;
открытие/закрытие консультации без отправки. Одна пакетная инспекция light,
dark и accessibility Dynamic Type в iPhone portrait (единственное заявленное
семейство/ориентация). При дефектах одна правка и подтверждающая инспекция.
Непроверенные VoiceOver, hardware, error/empty и отправка явно отмечаются.
Успешные mock/fixture тесты не заменяют реальный путь. Независимый exact-head
review и защищённый CI перед merge. Серверный деплой не входит в изменение.

Общий итоговый E2E, новая контентная волна, App Store readiness отложены
владельцем; это только точечная проверка изменённого экрана.

## Основания

- [Apple HIG: Disclosure controls](https://developer.apple.com/design/human-interface-guidelines/disclosure-controls): нативное раскрытие второстепенных сведений.
- [SwiftUI DisclosureGroup](https://developer.apple.com/documentation/swiftui/disclosuregroup).
- Действующий [дизайн-контракт EVO](design-contract.md); Impeccable native iOS guide.

## Квитанция

2026-09-20, iPhone 17 Pro / iOS 26.5, portrait, настоящий существующий EVO QA
Student. Проверенный код — исходное implementation head `1b9c2ace`; subsequent
rebase переносит те же iOS blobs без изменения. Начальная установленная версия
приложения не имела записанного SHA; baseline source review выполнен на `485f3ce0`.

**Сборка:** Xcode build succeeded. Для рабочего Auth/Keychain нужна обычная
ad-hoc подпись симулятора. Первая сборка с `CODE_SIGNING_ALLOWED=NO` запускалась,
но не восстановила сессию и не прошла доступ после входа. Сборка с подписью ниже
восстановила существующую QA-сессию, последующие установки сохранили вход.
Это локальный дефект способа сборки, не изменение прав или серверной схемы.
Реквизиты использованы процессно из владельческого ignored-файла; в Git/логи
не добавлены. Повторный вход через форму и отдельный read-only Auth/RPC probe
подтвердили существующую identity, Student authority и ровно одно собственное
дело. Данные дела, права, пароль и формы заявок не изменялись.

```sh
xcodebuild -project ios/EVOAdmissions.xcodeproj -scheme 'EVO admissions' \
  -destination 'platform=iOS Simulator,id=C3A01C7C-4C22-4DE8-8BD8-7DEC5F786FF2' \
  -derivedDataPath .next/ios-build CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=- build
```
