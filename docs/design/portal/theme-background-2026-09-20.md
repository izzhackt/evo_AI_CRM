# B-4: фон портала следует выбранной теме

Проверено 20.09.2026. Это один подтверждённый дефект B-4; весь проход
доступности portal/iOS этим не закрывается.

## Причина и изменение

`Shell.tsx` сохраняет `pt-content v3-world` для совместимости вложенных
CRM-компонентов. `.v3-world` задаёт светлый `--bg: #f3f3f3`, тогда как
портальные заголовки уже используют тёмную палитру `--pt-*`. На реальном
мобильном экране избранного получился почти белый текст на светлом фоне:
`rgb(242,239,233)` поверх `rgb(243,243,243)`, контраст около **1.03:1**.
Наблюдение зафиксировано до правки в квитанции B-5.

Добавлено только `background: var(--pt-bg)` для `.pt-content.v3-world`
в `src/app/(portal)/portal.css`. Класс совместимости, общие staff-токены,
типографика, размеры, вложенные поверхности и поведение не изменены.
Scope согласован до кодирования в B-4 записях `EVO_LAUNCH_PLAN.md` и
`PLAN_CHANGES.md`, вошедших в main через PR #940.

## Настоящий путь проверки

Исходная ревизия приложения — `87514d276b439fa45b75664d8194ed48415dabb1`
плюс указанная CSS-правка. Node 22.23.1, Next.js 16.3.4 **dev** на
`127.0.0.1:3142`, существующая managed Supabase, обычная сессия ранее
разрешённого QA Student. Это не production build и не серверный релиз.

В изолированном IAB проверены существующие данные, без подмены DOM/ответов:

| Экран | Проверка |
|---|---|
| `/portal/universities` | 390×844, light/dark; каталог и фотографии читаемы |
| `/portal/favorites` | 390×844, light/dark; существующие избранные сохранены |
| Детальная страница университета из каталога | 390×844, light/dark; заголовок, описание и фото |
| `/portal` — «Моё поступление» | 390×844 и 1280×900, light/dark; портальный фон и вложенная legacy-панель помощи |

На мобильном экране document scroll width = 380 при viewport 390;
на desktop = 1270 при viewport 1280: горизонтального переполнения нет.
Скриншоты после правки просмотрены для тёмной детали университета,
светлой мобильной главной и тёмной desktop-главной; они не публиковались
в Git. Цвета остальных состояний сверены через computed styles.

| Состояние | Цвет текста / фона, RGB | Контраст |
|---|---|---|
| Dark, основной текст | 242,239,233 / 20,19,17 | 16.18:1 |
| Dark, вторичный текст | 163,157,148 / 20,19,17 | 6.90:1 |
| Light, основной текст | 25,23,20 / 247,245,242 | 16.44:1 |
| Light, вторичный текст | 107,102,96 / 247,245,242 | 5.22:1 |
| Legacy-панель помощи, обе темы | 32,32,32 / 255,255,255 | 16.29:1 |

Значения рассчитаны по относительной яркости фактически полученных RGB.
Светлая поверхность старой панели и её собственный тёмный текст сохранены.
Ссылки после завершения существующего перехода темы используют ожидаемый
тёмный accent `rgb(255,74,87)`. Временные эмуляции темы и viewport сброшены.
