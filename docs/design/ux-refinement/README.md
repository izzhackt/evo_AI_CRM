# Страничные задания EVO UX

функциональные требования: [CRM/admissions](../../archive/plans/2026-09-20-crm-ux-and-admissions-plan.md).

Это анализ исходников и доступных реальных экранов, а не результат внедрения.
Номера строк привязаны к указанному в каждом brief SHA. Личные снимки не
публикуются. Реальные операции записи, непоказанные состояния и production
приёмка не предполагаются выполненными.

- [Главная и продажи](sales.md)

Каждый brief задаёт границы, сохраняемые возможности, последовательность
небольших изменений и реальные критерии приёмки. Общий исполнитель согласует
shared-файлы и контракты; результаты одного экрана не считаются доказательством
всего продукта.
