# Фильтры списков — панель «Фильтры» — 14.11.2026

Слова владельца: «не понятно что делает каждый фильтр… может просто рядом с поиском будет типа знак фильтра»;
«сделай поисковик меньше»; про первую версию панели с чипами в рамках — «it looks messy».

**Взяли.** Короткий поиск (до 24rem), одна кнопка «Фильтры» с точкой, выбранное — чипами «Название: значение ×» на странице;
панель — строка на фильтр с текущим значением, раскрывается ровным списком с кружками и числами; раскрыт один раздел за раз.

**Не взяли.** Варианты-чипы в рамках внутри панели («it looks messy»); сортировку чипом на странице (это порядок, а не отбор);
отдельную страницу фильтров — панель поверх списка даёт то же и не уводит со списка.
