# Ряды вкладок без линии снизу — 14.11.2026

Решение владельца: сделать внешний вид минималистичнее и удобнее, информацию и устройство экранов не менять.

**Взяли.** Под рядами вкладок нет линии во всю ширину; выбранную вкладку отмечает одна нейтральная плашка `.v3-choice`.
Рамка фокуса — внутри вкладки (`data-tab-ring="inset"`), её не срезает край ряда.

**Не взяли.** Верх бокового меню («Создать задачу», колокольчик, поиск) остался как был по решению владельца.
