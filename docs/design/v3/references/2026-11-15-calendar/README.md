# «Календарь» по образцу «Акылмана» — 15.11.2026

Решение владельца (в чате, 15.11.2026; пересказ по смыслу): выделять задачи по смыслу и сделать календарь удобнее; убрать
отдельный ряд «‹ Сегодня ›»; на телефоне показывать дни недели; доработать колонку часов; добавлять задачи кнопкой «+» в
календаре; улучшить вид формы «Новая задача»; взять за образец календарь «Акылмана».

**Взяли из «Акылмана».** Заголовок — сам период; один ряд «вид · + ‹ Сегодня ›»; левая панель с мини-месяцем и фильтром задач;
вид «Список» по дням; повестка рядом с днём; линия «сейчас»; «+» на дне.

**Не взяли.** Его цвета: блоки залиты только по смыслу (просрочена — светло-красный с ребром и словом, срочно — светло-жёлтый
с «срочно»), остальное нейтральное — цвет в EVO значит состояние, а не вид задачи. Красную «+ Добавить задачу» вверху — на экране
одна «Создать задачу» (Э7), здесь — тихий «+». Вид «Год» и «Ближайшее» — нужны новые чтения. Время у новой задачи (клик по часу) —
нужна поддержка в форме и на сервере.
