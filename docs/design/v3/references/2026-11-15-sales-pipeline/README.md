# «Воронка продаж» спокойнее — 15.11.2026

Решение владельца (в чате, 15.11.2026; пересказ по смыслу): первым из обхода — «Воронка продаж», с картинками «было / стало».
Первая проба строки фильтров показалась неаккуратной; карточки лидов — перегруженными; списки колонок должны начинаться на
одной высоте; срок — в правом верхнем углу карточки, инициалы — в правом нижнем; красная «Добавить лида» на телефоне слишком
крупная — лучше знак «+».

**Взяли.** «Ответственный» и «Срок» — в панели «Фильтры» (как у «Студентов»); «Переданы» прилипает к правому краю ряда вкладок;
списки колонок начинаются на одной линии; карточка — четыре данных: имя, срок словом в правом верхнем углу, действие и инициалы
в правом нижнем; на телефоне — красный «+» вместо кнопки во всю строку.

**Не взяли.** Подпись «Ответственный» внутри рамки и «Срок» плашками над вкладками — первая проба, выглядела неаккуратно. Срок внизу
карточки в узкой колонке — владелец вернул его в правый верхний угол. «На этапе N дн» на карточке — осталось в панели лида.
