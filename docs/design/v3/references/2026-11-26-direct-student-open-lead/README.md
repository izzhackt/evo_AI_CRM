# «Новый студент» забирает открытый лид продаж — 26.11.2026

Что случилось (в чате, 26.11.2026; пересказ по смыслу): Admin не может добавить студента через «Новый студент» в «Воронке
поступления». Форма отвечала «Этот человек уже есть в продажах как открытый лид… Дело появится, когда продажи передадут его в
поступление». В голосовом сообщении команды пояснение: продажники в CRM не работают, кнопку передачи в продажах никто не нажмёт.
Куратору нужно сразу заводить студента самому.

**Взяли (миграция 378).** Команда сотрудника `create_admissions_student_case_v1` больше не отказывает из-за открытого лида. Она
берёт этот лид (самый свежий, как и раньше) и его клиента и заводит дело на них:
- лид становится «переведён» (`converted`) и уходит с доски продаж;
- новые клиент и лид не создаются;
- куратор, этап, анкета, заметка, договор и оплаты — из формы;
- условия продажи, если продажи их уже записали, дополняются стоимостью и датой договора из формы;
- в квитанции и журнале `case.create` стоит `lead_taken: true`.

Форма говорит «Лид из продаж перенесён в дело. Студент добавлен…».

**Не взяли.**
- Дело в работе у человека — по-прежнему отказ, найдите его в «Студентах»: второе дело одному человеку не заводится.
- Служебный импорт из отчёта продаж (`import_admissions_student_case_v1`) не меняется: для открытого лида он, как и раньше,
  отвечает строкой `lead_exists` и ничего не создаёт.
- Передача 088 («продажи передают, куратор принимает») не трогается. Она остаётся для тех, кто работает в продажах.
- Слова отказа `lead_exists` в форме остались: их показывает база без миграции 378, пока владелец её не применил.
