# Референсы для V3

Каждый референс попадает сюда вместе с решением по нему. Референс без
записанного решения — это доска настроения, а не проектный ввод: через неделю
никто не помнит, что именно из него брали и почему.

## Формат

Один файл на референс: `NN-короткое-имя.md`, рядом само изображение.

    ## Что это
    Откуда взято, что за продукт, зачем показано.

    ## Что берём
    Конкретно: композиция / плотность / типографика / поведение / что-то одно.

    ## Что НЕ берём
    Не менее важно. Обычно это палитра и шрифты — визуальный мир EVO уже
    закреплён logobook'ом и токенами.

    ## Куда применяется
    Экран, компонент, состояние.

    ## Чем это проверяется
    Как поймём, что перенесли правильно, а не «похоже».
