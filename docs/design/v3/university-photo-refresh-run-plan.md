# Свежие фотографии университетов — 2026-09-18

Статус: RELEASED59 — готовые59 замен выложены; дальнейший подбор остановлен
владельцем. Полный143-image/mobile проход не заявляется завершённым.

Владелец просит заменить старые фотографии университетов на свежие и качественные
в `https://app.evoadmissions.com`. Изменение распространяется на существующий
общий каталог Student/Staff. База выполнения — `main` после PR822; отдельная
ветка `izzhackt/university-photo-refresh`.

## Объём

- Проверить все 143 используемых фотоключа. В реестре 144 записи; неиспользуемый
  резерв HIT Shenzhen не входит в пользовательский каталог.
- Заменить устаревшие, исторически нерелевантные или некачественные фотографии
  на проверенные реальные изображения действующего кампуса. Приоритет —
  официальные фотографии 2024–2026 годов и современные открыто лицензированные
  снимки; подходящие уже свежие кадры сохраняются.
- Не путать дату проверки страницы, дату публикации и дату съёмки. Если съёмка
  не датирована, не называть кадр фотографией 2026 года. Не подменять кампус
  рендером, логотипом, рекламным коллажем или посторонним зданием.
- Сохранить фотоключи, университеты, программы, цены, сроки, DTO и права доступа.
  Только реестр `src/lib/university-photo-library.json` и публично-безопасные
  источники/evidence; миграции, повторная публикация карточек и записи в БД
  не нужны. Менять renderer только при доказанной проблеме с новым форматом.
- Сохранить настоящего автора, источник, условия использования и подписи.
  Официальные URL без свободной лицензии остаются прямыми встраиваниями с
  честной атрибуцией; не копировать их в публичный Git или Storage. Не генерировать
  и не ретушировать фотографии.

## Проверка и выпуск

1. Для каждого используемого ключа записать replace/retain/unresolved, первичный
   источник, обоснование свежести, размеры и результат визуальной проверки.
   HTTP200 недостаточно: проверить реальное изображение и ограничения встраивания.
2. На реальном приложении с существующей авторизованной QA Student-сессией
   проверить изменённые изображения в каталоге, правильность кампуса, подписи,
   кадрирование и загрузку (`complete`, `naturalWidth > 0`); проверить список и
   подробные карточки, desktop и mobile. Не создавать демонстрационные данные.
3. Выполнить только затронутые проверки существующего настоящего пакета каталога
   и `git diff --check`; независимое review точного HEAD и защищённые короткие PR
   проверки обязательны. Не повторять тяжёлый набор миграций/RLS/всех тестов.
4. Обычный merge, действующий облегчённый managed release с одним immutable build,
   реальными проверками и rollback. После выпуска проверить изменённый каталог на
   `app.evoadmissions.com`, exact SHA/image/health/accepted/pending/arm и сохранить
   итоговый отчёт. Не заявлять полное обновление, если остались нерешённые источники.

## Начальные факты

- В 91 подписи указан год до2020; это анализ подписей, не новая проверка EXIF.
- APU показывает UCTI2011 вместо действующего кампуса MRANTI; MMU2009, INTI2007
  (330px), UniKL2007, MSU2015 (851×315), Tsinghua2003 требуют первоочередной замены.
- `UniversityPhoto` общий для Student/Staff, фиксированный источник выбирается
  по существующему `photoKey`; `referrerPolicy=no-referrer`, подписи и ошибка
  загрузки уже предусмотрены. Изменение JSON не меняет версии карточек в Supabase.
- Текущие официальные галереи проверяются онлайн. Правила атрибуции:
  https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia
  и https://creativecommons.org/licenses/by-sa/4.0/.
