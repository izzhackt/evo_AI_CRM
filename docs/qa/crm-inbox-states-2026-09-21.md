## Изменение

`/v3/inbox` различает пустую страницу истории, отсутствие совпадений фильтров
и пустую доступную очередь. Новый сброс очищает поиск и «ждут ответа» вместе.
При пустой очереди без выбранного диалога нет второй бессодержательной панели.
Открытый диалог, независимые курсоры, ограничения доступа, команды и история
сохранены. Узкий срез пункта 9 не завершает все возможности Inbox.

Сохранённое состояние `crm_primary` читается один раз для списка без выбора
либо выбранного диалога этой сессии. Нет записи — состояние не подтверждено;
ошибка только этого необязательного чтения — явное сообщение о недоступности
состояния. Ошибки очереди/переписки/контекста/команд остаются в прежнем error
boundary. Готовность требует существующего freshness helper и WORKING;
исторические другие сессии не наследуют здоровье текущего WhatsApp.
Ни этот статус, ни его отсутствие не предоставляют право отправки.
