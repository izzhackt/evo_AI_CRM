мобильной ширине. Логотип, меню, «Создать задачу», уведомления, права и
обработчики сохранены; значения для десктопа восстановлены через `md:`.
Impeccable применён при выборе отступов; существующая типографика EVO сохранена.

Один обычный существующий Admin вошёл через форму и открыл
`/v3/universities/manage` в изолированной локальной среде со схемой 001–238.
Выполнен один проход 1440 → 390 → 320 px и одна последовательность клавиатуры.
Preview роли, новые пользователи, фикстуры и бизнес-записи не создавались.

по Escape с возвратом фокуса. Задача не создавалась, уведомления не помечались
прочитанными, формы каталога не отправлялись.

## Данные и закрытие сессии

Сняты исходное состояние, результат после UI и финальное состояние после
собственного logout 204. Все 290 бизнес-таблиц, каталог, эффекты и исходные
Auth sessions/refresh/AMR сохранены. Допущены только обычные метаданные
собственного входа и два его Auth-аудита. Равенство всех метаданных Auth не
заявляется. Браузер закрыт, собственный файл сессии удалён после сверки.

Один SIGTERM остановил только собственную группу приложения; supervisor
подтвердил exit 0. Проверка порта после остановки завершилась STOP: 98 попыток
за ограниченные 10 секунд, errno 48. Исходная квитанция сохранена. Отдельная
последующая проверка без сигналов подтвердила отсутствие группы и listener и
свободный порт 33270. Независимый reviewer принял закрытие; среда передана B1018.

## Границы результата

Это локальная проверка общей шапки под обычным Admin. Масштабирование только
текста в браузере не выполнялось: доступный CLI не предоставлял проверенного
управления им. Другие роли и отсутствующие варианты бейджей имеют только
доказательства по коду. VoiceOver, нативное приложение, полный E2E, production
и завершение всего пункта 22 или плана 1–36 не заявляются.
