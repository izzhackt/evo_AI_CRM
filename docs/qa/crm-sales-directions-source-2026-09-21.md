# Направления отчёта продаж: проверка исходников

21 сентября 2026; base main `a23490f746c9d13398712eed5e26dffd2330760b`.
Это source-only срез принятого пункта 7, не приёмка SQL/Auth/UI или production.

Миграция 233 добавляет только две read-only функции. Авторизация организации
и каждой записи применяется до DISTINCT; значения берутся из всех разрешённых
периодов и архивных состояний. Непустые строки сохраняются точно, C collation
задаёт различение и порядок. Неподходящие старые значения и превышение 1000
вызывают явную ошибку, не скрытую потерю вариантов. v1/v2, записи и их ACL не меняются.

Отдельный DTO проверяет организацию, точные ключи, уникальные строки и размер.
Одинаковый валидатор View/SSR считает 500 Unicode code points без нормализации.
Native GET select сохраняет все текущие параметры; отсутствующее в списке
значение URL остаётся выбранным с пояснением. При ошибке списка остаётся
ввод точного направления с видимым объяснением; ошибка не выдаётся за пустой успех.
Редактор/preview не запрашивают этот список. Impeccable Operate/adapt/craft-floor
применён; сохранены сетка, токены, label, min44px и обычная кнопка «Показать».

Проверки исходников: 17/17 целевых Node tests (7 новых границ DTO/выбора, 4 поиска,
6 прежнего register), scoped ESLint, `npm run typecheck` и `git diff --check` — PASS.
Первый прямой `tsc` в новом worktree остановился на отсутствующем generated
`next-env.d.ts` и типе PNG. Стандартный script с `next typegen` восстановил
служебные типы и завершился успешно; продуктовый код для обхода не менялся.
SQL/PLpgSQL разобраны существующим pglast; это статический разбор, не SQL execution.

Далее в выделенном ROOT окне после B232: реальный local apply, ordinary Auth
права/tenant и полный разрешённый набор, исходная cardinality/filterability,
выбор/сброс/возврат в UI desktop/mobile. Новые fixtures, пользователи и бизнес-
записи не нужны. Непредставленные в существующих данных >1000, legacy-control,
>50 и populated archive случаи останутся прямо отмечены как непроверенные.

[actual-квитанции](crm-sales-directions-actual-2026-09-21.md). Выше сохранён
исходный source-only срез35499c33; он не переименован в реальный прогон.
