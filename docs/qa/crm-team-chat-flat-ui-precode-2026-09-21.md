## Выполнено

- ROOT выделил read-only окно после завершения callback UI. Перед запуском
  проверены effects/actions: чтение истории/изменений не вызывает read command;
  markRead доступен только через явную кнопку; composer на mount читает draft,
  а пишет sessionStorage только по вводу/отправке. Эти действия не выполнялись.
- Существующий QA Student1 вышел обычной кнопкой; существующий QA Sales вошёл
  обычной формой. Ни аккаунты, ни пароли, ни роли не создавались/менялись.
- Открыт текущий чат с сохранённой разрешённой LOCAL A15c QA историей:56 сообщений
  в двух каналах. Никаких новых сообщений или fixtures при осмотре не добавлено.
- Desktop1280×900: общая история, поиск `message 55`, переход «К обсуждению».
  Найденный исходный ответ55 виден вместе с исходными1/2 в отдельном aside.
- Mobile390×844: то же обсуждение, возврат и закрытие поиска. Измерены
  innerWidth=390, documentElement.scrollWidth=390, body.scrollWidth=390.
- Снимки/DOM сохранены приватно. Composer не редактировался, mentions/read
  buttons/send/edit/delete/moderate не вызывались. Обычные private Realtime
  подписки и read refresh работали без изменения истории.

## Результат и ограничения

Полная сверка всех281 business tables и сохранённого snapshot metadata дала
точное равенство до/после: данные/хеши, schema ledger, функции, индексы,
constraints/policies/triggers, прежние read markers, Auth user/identity counts
сохранены. `changedStateKeys=[]`. Auth sessions при обычном logout/login
изменились; их неизменность не заявляется. Chrome localhost session остаётся Sales.

Собственная вкладка1055896636 закрыта, device emulation сброшена, dev-server33235
остановлен. Первоначальный Turbopack dev не запустил страницу из-за node_modules
symlink за filesystem root; тот же исходник осмотрен через webpack dev.
Это ограничение локального запуска, не найденный runtime-дефект чата.

Осмотр выявил избыточную высоту сообщений, отсутствие previews/времени каналов,
двойной composer при поиске/обсуждении и потерю места истории после закрытия
поиска. Наблюдения и предлагаемые изменения — в
[precode](../EVO_TEAM_CHAT_FLAT_UI_PLAN_2026-09-21.md).
QA history не является клиентской приёмкой; не проверялись другой автор,
непрочитанное после авто-seen, отправка,320px, тёмная тема, IME или screen reader.
