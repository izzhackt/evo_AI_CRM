## Обычный Auth и RPC

Использованы существующие тестовые Admin и Student через обычный password
login локального Supabase. Новые аккаунты, сообщения и другие бизнес-данные
не создавались. Выполнен один согласованный набор проверок:

| Запрос | Фактический результат |
| --- | --- |
| Admin, своя организация | HTTP 200; действующий strict decoder и независимый SQL oracle согласны |
| Admin, отсутствующая организация с нулевым UUID | HTTP 403, SQLSTATE 42501 |
| Анонимный запрос | HTTP 401, SQLSTATE 42501 |
| Student | HTTP 403, SQLSTATE 42501 |

Ответ Admin содержит три канала: два с последним сообщением другого автора
и один пустой. Время двух сообщений сверено с `created_at` той же строки,
независимо приведённым к UTC с шестью дробными цифрами; пустой канал вернул
`null`. Исходные семь полей вложенного preview и данные с Unicode сохранились.

В имеющихся данных нет preview собственного сообщения, reply, tombstone
или длинного текста. Для этих сочетаний остаются адресные source-тесты;
новый живой результат не заявляется. Отказ для нулевого UUID подтверждает
обработку отсутствующей организации, а не доступ к наполненному чужому tenant.
