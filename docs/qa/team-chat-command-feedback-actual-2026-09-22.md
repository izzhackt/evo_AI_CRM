## Что проверено

После отдельной передачи ROOT16 обычный существующий Admin вошёл через форму
CRM и открыл существующее последнее неудалённое сообщение общего канала.
Открыта штатная форма модерации, введена причина. Затем браузер переведён
offline и один раз нажата кнопка подтверждения. Единственный запрос moderate
завершился `net::ERR_INTERNET_DISCONNECTED`, без ответа сервера. Повтор не
нажимали; других POST в отслеживаемом batch не было.

Показан точный текст: «Не удалось подтвердить удаление. Сервер мог уже удалить
сообщение. Повторите тот же запрос, чтобы проверить результат.» Причина
сохранена в заблокированном поле; ID сообщения, версия и requestId соответствуют
исходной команде. Зафиксирован переход кнопки: подтверждение → заблокированная
«Удаляем…» → доступная «Повторить тот же запрос».

Исполнитель и независимый reviewer просмотрели оба снимка ошибки. На320px
текст целиком переносится под причиной и кнопками; на1440px остаётся внутри
панели чата. documentWidth совпал с viewportWidth; ширина формы и её scrollWidth
равны320/320 и892/892. Горизонтальной прокрутки формы и обрезанных кнопок нет.
После снимков чат размонтирован переходом на about:blank при offline;
сеть восстановлена только после размонтирования.
