# EVO Admissions 1.0: документы для App Store Connect

Тексты и ответы, которые владелец вставляет в App Store Connect, и чеклист выпуска. Сверены с кодом ветки `izzhackt/ios-app-store-1-0` (PR #1172) 07.10.2026. Черновики писались в `output/app-store/store-docs/` основной папки (вне Git); в Git лежат эти версии, копии в `output/` приведены к ним 07.10.2026 (там же лежит `README.md`).

| Файл | Что внутри | Куда в App Store Connect |
| --- | --- | --- |
| `owner-checklist.md` | Решения владельца Р1..Р12, порядок выпуска, шаги от вступления в Apple Developer Program и перевода в Organization до выпуска, список стран, кто что делает | Весь путь |
| `listing-ru.md` | Название, подзаголовок, рекламный текст, описание, ключевые слова, категории, ссылки (основной язык) | «App Information», страница версии |
| `listing-en.md` | То же на английском и выбор английской локали | Локализация English |
| `app-privacy.md` | Ответы App Privacy, их соответствие файлу приватности, карта «данные, экран, код» | «App Privacy» |
| `age-rating.md` | Ответы анкеты возрастного рейтинга, итог 4+ | «App Information» → «Age Ratings» |
| `review-notes.md` | Шаблон «App Review Information» и текст «Notes» для проверяющего | Страница версии, «App Review Information» |

Решения владельца 07.10.2026, на которых написаны документы (подробности в `owner-checklist.md`):

- Аккаунт Apple Developer: сейчас Individual, для TestFlight. До публичного выпуска в App Store членство переводится в Organization через Apple Developer Support (правило 5.1.1(ix), Р1, шаг 2.1).
- Удаление аккаунта: в течение 30 дней; договоры и платёжные записи хранятся обезличенными столько, сколько требует закон. Функцию строит отдельный PR «Удаление аккаунта по запросу» (Р4). `review-notes.md`, экран и политика на сайте говорят одно и то же.
- Страны: СНГ и Азия, без ЕС и без Китая. 39 витрин в шаге 9 чеклиста предложили агенты, список ждёт финального взгляда владельца (Р2).
- Порядок выпуска: #1170 (восстановление пароля в вебе, пока не выпущен, ждём владельца) и PR об удалении выпущены, затем Organization, затем отправка на публичную проверку (раздел «Порядок выпуска и зависимости» в `owner-checklist.md`).
