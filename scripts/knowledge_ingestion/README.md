# Локальный конвейер знаний EVO

Этот инструмент готовит экспорт Google Drive и Gmail для последующей проверки
в Codex. Он не использует OpenAI API, не требует API-ключ и не изменяет исходный
архив.

Что создаётся в указанной папке результата:

- `Манифест источников.jsonl` — SHA-256, тип, размер, дата, классификация,
  результат извлечения и все пути одинаковых файлов;
- `Состояние обработки.json` — checkpoint для безопасного повторного запуска;
- `Извлеченный текст` — только локально извлечённый деловой текст;
- `Очередь проверки Codex` — ограниченные пакеты для следующего этапа;
- `Отчет последнего запуска.json` — счётчики без содержимого документов.

Корзина Google Drive, Spam/Trash Gmail, секреты и распознанные личные документы
заявителей не попадают в извлечённый текст. PDF без текстового слоя получает
статус `нужен_OCR`; автоматический OCR таких файлов намеренно не выполняется.

Пример реального запуска:

```bash
python3 scripts/knowledge_ingestion/prepare.py \
  --drive-root "/путь/к/Google Drive" \
  --gmail-mbox "/путь/к/Gmail.mbox" \
  --authorized-root "/путь/к/Входящие кандидаты" \
  --output "/путь/к/Входящие кандидаты/Конвейер импорта"
```

Повторный запуск с неизменившимися источниками должен показать
`"новая_работа": 0`. Ненулевой код завершения означает реальную ошибку парсера
или повреждённый источник; детали остаются в манифесте, а не скрываются.

## Проверка через Codex

После подготовки пакеты можно проверять установленным Codex CLI. Команда
использует текущую авторизацию Codex, а не OpenAI API-ключ. Результат каждого
пакета проверяется по JSON-схеме и повторно не запускается. Переменные окружения
с API-ключами, токенами, паролями и секретами не передаются дочернему процессу.
SHA-256 каждого пакета сверяются с расположенным рядом K2-манифестом; другую
папку очереди команда отклонит. Одна попытка ограничена 600 секундами, чтобы
сбой Codex не оставлял весь конвейер зависшим:

```bash
python3 scripts/knowledge_ingestion/review.py \
  --queue "/путь/к/Конвейер импорта/Очередь проверки Codex" \
  --authorized-root "/путь/к/Входящие кандидаты" \
  --output "/путь/к/Входящие кандидаты/Результаты проверки Codex"
```

Публикация разрешена только во внутреннюю базу. Решения Codex `escalate`, а
также любые утверждения о ценах, визах, гарантиях, возвратах, договорах,
обязательствах или секретах принудительно попадают в `Требует решения`.
Различающиеся утверждения одного раздела также эскалируются, поскольку без
машинно подтверждённого уровня источника нельзя безопасно выбрать победителя:

```bash
python3 scripts/knowledge_ingestion/publish.py \
  --reviews "/путь/к/Результаты проверки Codex" \
  --queue "/путь/к/Конвейер импорта/Очередь проверки Codex" \
  --authorized-root "/путь/к/Внутренняя база знаний ЭВО" \
  --vault "/путь/к/Внутренняя база знаний ЭВО/Утверждено для внутреннего ИИ"
```

Корень внутреннего vault дополнительно привязан marker-файлом `.evo-vault.json`
к своему точному canonical path. Копия marker в другой папке проверку не пройдёт.
