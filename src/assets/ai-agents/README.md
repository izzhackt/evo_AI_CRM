# Маскоты ИИ-агентов: происхождение

Семь картинок для хаба «ИИ-агенты», шапки страницы агента и чата; подключены в
`src/components/staff/ai-agents-next/agent-mascots.ts`. Здесь записано только то, что известно.
Остальное не угадываем: AGENTS.md велит проверять происхождение и права на материалы.

## Что известно

- Сгенерированы в Google Flow одним из участников команды, около 2026-11-12. В репозиторий добавлены
  в PR #1450 (2026-11-12).
- Семь файлов, по одному на агента из каталога (`src/lib/ai-agents/contract.ts`), имя файла = ключ агента.
- Формат WebP, 200 × 200 px, около 10 КБ каждый.
- По справке Google Flow («Get started with Google Flow»,
  <https://support.google.com/flow/answer/16353333>), результаты Flow несут невидимый водяной знак SynthID.
  Видимый знак Flow включается отдельно. Мы знака не видим и не проверяли.
- В файлах нет блоков EXIF и XMP: только изображение с прозрачностью (блоки RIFF `VP8X`, `ALPH`, `VP8 `).
  Оригиналов и исходных файлов Flow в репозитории нет.
- Репозиторий публичный: файлы доступны всем.

## Права

Лицензия и условия использования результатов Google Flow для такого применения (публичный репозиторий,
продукт EVO) не проверены: проверку подтверждает владелец. Пока он не подтвердил, права на картинки не
считать подтверждёнными. Если картинки заменят, обновите таблицу и этот файл.
