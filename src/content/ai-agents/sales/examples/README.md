# Эталонные диалоги

Сюда кладите эталонные диалоги агента: один файл `<короткое-имя>.md` на сценарий
(реплика клиента или сотрудника, ответ агента, вызванные инструменты). Файлы этой папки
НЕ попадают в инструкцию и не меняют хеш конфигурации: они нужны людям и тестам.

Сейчас рабочие примеры диалога лежат в `rules.md`, раздел «Примеры диалога», и
попадают в инструкцию агента вместе с регламентом.
