# Схема контента «Путь поступления»

Версия схемы: 1. Дата: 16.10.2026. План: `docs/EVO_STUDENT_APP_V2_PLAN_2026-10-16.md` §8.
Контракт выбора и RPC для веба и iPhone: `docs/portal/country-timeline-contract.md`.

Семь файлов: `cn.json`, `my.json`, `ae.json`, `tr.json`, `it.json`, `cz.json` (страны продукта) и `undecided.json` (общий маршрут). Веб читает их через `src/lib/portal/country-timeline.ts`, iPhone берёт те же файлы ресурсами bundle (`ios/project.yml`). Строгий парсер проверяет каждый файл при импорте; неверный файл ломает сборку и тесты (`tests/portal-country-timeline.test.mjs`).

Это первая продуктовая версия схемы. От черновика контента 16.10 (`output/student-app-v2/content/timeline/SCHEMA.md` канонического checkout, вне Git) она отличается так: одна оговорка `disclaimer` стала тремя `disclaimers`; у пункта появился `status` (`confirmed` или `verify`), а внутренняя пометка `review` убрана; у файла появились `contentVersion` и `validUntil`; у текстов с годом есть вариант `undated`; у шага может быть `links`; внутренние источники без пути к документу; общий маршрут без сроков (`intake.model = none`, `timing = null`).

## Файл

| Поле | Тип | Смысл |
| --- | --- | --- |
| `schemaVersion` | `1` | Версия этой схемы. |
| `contentVersion` | целое ≥ 1 | Растёт при каждой правке текста файла. |
| `country` | строка | `CN`, `MY`, `AE`, `TR`, `IT`, `CZ` (имя файла в верхнем регистре) или `UNDECIDED` для `undecided.json`. |
| `name` | `L10n` | Название страны, ровно как в `src/lib/study-countries.json`; у общего маршрута «Общий маршрут». |
| `status` | `draft`, `owner_review`, `approved` | Своим таймлайном показывается только `approved`. Общий маршрут всегда `approved`. |
| `updatedOn` | `YYYY-MM-DD` | Когда текст сверяли с источниками. |
| `validUntil` | `YYYY-MM-DD` | После этой даты тексты с годом заменяются вариантом `undated`. Обновление на следующий набор планируется за два месяца до неё. |
| `kyStatus` | `needs_native_proofreading`, `proofread` | Кыргызский текст ждёт вычитки носителем, пока не `proofread`. |
| `intake` | `Intake` | К чему привязаны сроки. |
| `disclaimers` | `Disclaimers` | Три обязательные оговорки. |
| `steps` | `Step[]` | От 5 до 8 шагов по порядку. |
| `sources` | `Source[]` | Реестр источников. Каждый используется хотя бы одним шагом или пунктом. Студенту не показывается. |

`L10n`: `{ "ru": string, "ky": string }`, оба непустые, без даты.

`Text`: `{ "ru", "ky", "undated"? }`. Если в `ru` или `ky` есть абсолютная дата (год 19xx или 20xx, либо дата `дд.мм.гггг`), поле `undated` обязательно: это `L10n` без даты, которое показывается после `validUntil`. В полях, которые можно скрыть (текст и `note` пункта, `note` шага, `intake.note`), `undated` может быть `null`: тогда после `validUntil` поле или пункт скрывается. Если даты нет, `undated` запрещён. Названия месяцев без года датой не считаются: календарь набора повторяется каждый год.

## Intake

| Поле | Смысл |
| --- | --- |
| `model` | `annual`: один главный набор в году (CN, IT, TR, CZ); `rolling`: сроки от интейка вуза (MY, AE); `none`: только общий маршрут, без сроков. |
| `reference` | Для `annual` месяц начала учёбы `YYYY-MM` (сейчас `2027-09`), иначе `null`. |
| `label` | `Text`, подпись над таймлайном. |
| `note` | `Text`, необязательно. |

## Disclaimers

Три `L10n`, все обязательны и проверяются по началу или концу фразы:

| Ключ | RU | KY |
| --- | --- | --- |
| `timing` | начинается с «Сроки ориентировочные» | начинается с «Мөөнөттөр болжолдуу» |
| `documents` | начинается с «Окончательный список документов зависит от » | начинается с «Документтердин акыркы тизмеси » |
| `decisions` | «Решение о зачислении … ; EVO их не гарантирует.» | заканчивается «; EVO буларга кепилдик бербейт.» |

Отрицание в `decisions` единственное место, где допустимо слово с корнем «гарантир» или «кепилд».

## Step

| Поле | Смысл |
| --- | --- |
| `id` | `<файл>-<order>-<slug>`, например `cn-2-exams`, `undecided-3-documents`. Стабилен между версиями. |
| `order` | С 1 без пропусков. |
| `stageKeys` | Этапы дела из CRM: `intake`, `profile_and_route`, `documents`, `applications`, `decisions`, `visa_and_predeparture`, `arrival_and_adaptation`. В общем маршруте ровно один этап на шаг, по порядку. |
| `title`, `summary`, `doneWhen` | `Text`, нельзя скрыть. |
| `timing` | `Timing` у страны, `null` у общего маршрута. |
| `checklist` | `Item[]`, минимум один пункт `confirmed`, который остаётся и после `validUntil`. |
| `note` | `Text`, необязательно. |
| `links` | Необязательно: `[{ "id", "label": L10n, "url": "https://…", "appModule"?: "csca" }]`. С `appModule` ссылка ведёт в модуль приложения, если платформа его передала, иначе на `url`. |
| `sources` | ID из реестра файла. |

`Timing`: `from` и `to` вида `{ "value": целое, "unit": "week" | "month" }` (смещение от начала учёбы, одна единица, `from ≤ to`), `label` (`Text`, нельзя скрыть), `basis`: `owner_guide`, `official`, `evo_internal`, `estimate`. В файле со статусом `approved` срока `estimate` нет. Числа смещений студенту не показываются.

## Item

| Поле | Смысл |
| --- | --- |
| `id` | `<файл>-<order>-<NN>`, уникален в файле. |
| `who` | `student`, `evo`, `university`, `embassy`. Подписи: «Студент», «EVO», «Вуз» (KY «Университет»), «Посольство» (KY «Элчилик»). |
| `status` | `confirmed` показывается; `verify` скрыт, пока владелец или ОЗО не подтвердят. |
| `text` | `Text`. |
| `note` | `Text`, необязательно, мелкий шрифт. |
| `appliesTo` | `Text`, необязательно, условие над текстом («Если вам нет 18 лет»); нельзя скрыть. |
| `sources` | ID из реестра файла. |

Пункты `verify` на 16.10.2026: `my-6-01` (стойка ISAC в KLIA, правило от 12.10.2026, переспросить перед показом, расхождение D11) и `ae-2-01` (паспорт от 6 месяцев для резидентской визы ОАЭ, не сверено на icp.gov.ae, пробел G05).

## Source

`{ "id", "kind", "title", "url"?, "checkedOn" }`. `kind`: `owner_guide`, `evo_internal`, `official`, `university`, `secondary`. У внешних источников обязателен `url` (https), у внутренних (`owner_guide`, `evo_internal`) адреса и пути в файле нет: файл целиком лежит в bundle iPhone. Расшифровка внутренних ID ведётся в списке расхождений владельца (`discrepancies.md` черновика).

## Правила текста (проверяет парсер)

- RU и KY во всех текстах; KY помечен для вычитки носителем.
- Без длинного и короткого тире и знака минуса (U+2012…U+2015, U+2212). Дефис в словах допустим.
- Нет слов со смешением латиницы и кириллицы, кроме латинского термина с кыргызским окончанием («HSKга», «Universitalyде»).
- Нет обещаний: «гарантир…», «100 %», «точно получ…», «кепилд…», «сөзсүз аласыз».
- Нет внутренних сведений: «ОЗО», «отдел продаж», «регламент», «плейбук», «скрипт», «агентск…», EDUPRCHINA, скидки и промокоды, e-mail, телефоны; нет путей `~/`, `Downloads`, `EVO_Знания`.
- Цены только официальных госсборов с источником; суммы вузов и агентств называет куратор.
- Даты сессий CSCA в таймлайн не входят: шаг экзаменов Китая ссылается на модуль CSCA или на csca.cn.
